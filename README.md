# Vetinary Operations Suite 🐄🔬

An all in one internal desktop application built with Python (`Tkinter` and `SQLite`) to streamline veterinary pharmaceutical operations. 

![Operations Suite Ledger](ledger.png)

## Core Modules
1. Farm Credit Ledger:Track distributor and farm supply accounts,logging total bills,payments,and highlighting pending balances
2. Inventory Vault:Log incoming stock batches,track quantities,and monitor expiry dates for veterinary drugs
3. Formulation Batch Calculator:Instantly compute the exact raw chemical measurements required to manufacture scalable batches of products (e.g.,ExharCal Gel)

[Batch Calculator Module](calculator.png)

## Tech Stack
* Frontend:Python Tkinter (Native Desktop GUI)
* Backend Database: SQLite3 (Embedded, no installation required)
* Architecture:Tabbed UI with modular CRUD functions.
